# 🐦 Wren: The Agentic Security Proxy

Wren is a developer-first security layer for LLM applications. It provides real-time PII redaction, prompt injection protection, and tool-call monitoring.

## 🚀 One-Line Integration
Swap your OpenAI base URL to Wren and you are secured.
```python
client = OpenAI(base_url="http://localhost:8000/v1")
```
